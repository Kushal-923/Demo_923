# Chronos AI
Project Chronos: The AI Archeologist — a web-based AI tool that reconstructs fragmented digital text using Google Gemini and automated web search to generate contextual Reconstruction Reports.
<br>
1. Copy Files: 
   Copy the HTML file (`index.html`) and the configuration file (`config.js`) into your project directory.

   ```bash
   cp index.html config.js /path/to/your/project/

<br>
2. Update API Key: 
   Open config.js in any text editor and replace the placeholder value with your actual API key.

<br>
3. Run the Project: 
   Simply open the index.html file in your browser to run the project.
